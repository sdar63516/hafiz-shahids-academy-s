# Hafiz Shahid's Academy — Website 8.2

This is the normal website version of Hafiz Shahid's Academy.

## Included
- Old Academy website-style home/login UI
- Admin password login
- Student email OTP login via Brevo
- Trusted same-device student login
- Special student `hafizshahid` gets access to all courses
- Student dashboard, courses, purchased courses, lessons, materials, assignments, live classes, certificates and doubts
- Ask a Doubt + academy replies
- Existing Admin panel/backend/database
- Neon/Render persistence

## Intentionally disabled/removed
- PWA manifest
- Service worker / offline app shell
- Public clean-site JS/CSS shell
- Android/app-install dependency

The website does not require installation. Open it normally in a browser.
